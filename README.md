# Domino Chain Reaction Topple Sim

Place up to 50 domino tiles on a 700×400 canvas by clicking, then press Topple to trigger an animated left-to-right chain reaction where each fallen domino knocks over nearby neighbors.
A slow-motion replay button replays the sequence at 0.3× speed, and a counter tracks how many dominoes fell.
Press Reset to clear the canvas and start a new layout.
